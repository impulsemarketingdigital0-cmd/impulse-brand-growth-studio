# Impulsemarketingdigital

faça uma landing page para uma agencia de marketing chamada "Impulse", focados em trazer visibilidade e impulsionar as marcas para um outro nível, a logo é essa que voce vê na imagem anexada. o site deve ser bem moderno, beirando o futurista, com animações e etc. a paleta de cores é a que voce ve na logo, dando foco principal para o preto e roxo, para contato temos o whatsapp, como é a principal forma de contato, deve ser bem destacada no site

é interessante também uma área com um carrossel das logos das marcas para quem prestamos serviço
